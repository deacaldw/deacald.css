Getting started

Copy deacald.css and deacald.js into your project and link them.

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Geologica:wght@100..900&family=JetBrains+Mono:wght@400..700&display=swap">
<link rel="stylesheet" href="deacald.css">
<script defer src="deacald.js"></script>

Colours

Achievement popups

Toast and confetti

Confirm modal

Use the danger style only for actions that can't be undone.

const ok = await deacald.confirm({ icon: "☠️", title: "Permadeath", items: ["No hints."], confirm: "Take the challenge", cancel: "Not now" });
